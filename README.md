# Sales Platform — Internal Sales & Onboarding Platform

Закрита внутрішня веб-платформа для роздрібної компанії: автоматизує **онбординг**
нових продавців, **трекінг щоденних продажів**, **плани**, **бонусну механіку**,
**каталог товарів** і **звітність**.

Реалізовано **Варіант 1 — Web-платформа** з технічного завдання (`Seller Tracker SoW v1.0`).
> Telegram-бот (Варіант 2) та опційна інтеграція з 1С навмисно **не входять** у цей обсяг.

UI побудовано за наданими `wireframes_v1.html` (10 екранів).

## Стек

| Компонент        | Технологія                                  |
|------------------|---------------------------------------------|
| Frontend + SSR   | Next.js 15 (App Router), React 19, TypeScript |
| Стилі            | Tailwind CSS + Tabler Icons                 |
| Backend          | Next.js Route Handlers (Node.js)            |
| Database         | Prisma ORM + SQLite (легко → PostgreSQL)    |
| Автентифікація   | JWT у httpOnly cookie (`jose`, `bcryptjs`)  |
| Сховище файлів   | Локальне `public/uploads` (легко → S3)      |
| Експорт звітів   | `exceljs` (Excel) + `pdf-lib` (PDF)         |

## Запуск

```bash
npm install
npm run db:reset     # створює БД і наповнює демо-даними
npm run dev          # http://localhost:3000
```

Продакшн-збірка: `npm run build && npm run start`.

### Демо-акаунти (пароль у всіх: `password`)

| Роль    | Логін                   | Примітка                          |
|---------|-------------------------|-----------------------------------|
| Admin   | `admin@company.com`     | повний доступ до адмін-панелі      |
| Seller  | `olena@company.com`     | онбординг пройдено, є продажі      |

## Реалізований функціонал (за SoW, розділ 2)

- **2.1 Авторизація / користувачі** — єдиний вхід, ролі Admin/Seller, адмін створює,
  редагує, блокує, видаляє акаунти, задає індивідуальний % заробітку.
- **2.2 Примусовий онбординг** — при першому вході продавець замкнений на курсі;
  модулі (текст/відео/фото) → тест; прохідний бал **80%**, інакше повтор;
  адмін редагує модулі та питання; бачить статус/етап/% по кожному.
- **2.3 Плани й щоденні записи** — тижневий/місячний план індивідуально;
  обовʼязковий щоденний запис продажів; авто-розрахунок % виконання;
  індикація невнесеного запису.
- **2.4 Бонусна система** — продавець надсилає активність (тип, посилання, скріншот);
  фіксований бонус (конфігурується адміном); адмін модерує (нарахувати/відхилити).
- **2.5 Каталог** — товар (назва, опис, артикул, фото, ціна, колір, розмір, стать,
  категорія); додають і продавці, і адмін; видаляє лише адмін; пошук і фільтр.
- **2.6 Дашборд продавця** — план/факт, % виконання в реальному часі, баланс
  заробітку (% + бонуси), історія записів, прогрес курсу.
- **2.7 Адмін-панель** — зведена статистика, список продавців зі статусами,
  керування курсом, користувачами, бонусами, каталогом.
- **2.8 Звіти** — по продавцю (день/тиждень/місяць) і зведено; фільтр за продавцем
  і періодом; **експорт у Excel і PDF**.

## Структура

```
prisma/schema.prisma      # моделі даних
prisma/seed.ts            # демо-дані
src/lib/                  # auth, db, stats, reports, dates, format
src/middleware.ts         # захист маршрутів + розділення ролей
src/components/           # Shell, Catalog, Upload, UI-примітиви
src/app/login             # авторизація
src/app/dashboard/*       # інтерфейс продавця
src/app/admin/*           # адмін-панель
src/app/api/*             # REST API
```

## Перехід на продакшн

- **PostgreSQL**: у `prisma/schema.prisma` встановити `provider = "postgresql"`,
  задати `DATABASE_URL`, виконати `npx prisma migrate deploy`.
- **S3**: замінити локальний запис у `src/app/api/upload/route.ts` на S3-клієнт.
- **JWT_SECRET**: задати надійний секрет у середовищі.
